Cómo se juega

• El código se ejecuta línea a línea de arriba abajo; Los errores aparecen en la consola con el número de línea marcado en el margen.

• Comandos: avanzar(), avanzar(3), girarDerecha(), girarIzquierda(), plantar(), y los sensores faltaFlor(), hayRoca(), decir("...").

• Ctrl + Entertambién ejecuta; el progreso y tu código se guardan solos en el navegador.
