    Cómo se juega

    Escribes JavaScript de verdad en el editor y pulsas ▶ Ejecutar. Robi el robot jardinero obedece tus órdenes al instante: cada línea de código es una orden.

    Los comandos de Robi

    avanzar()Mueve a Robi una casilla hacia delante.
    avanzar(3)Lo mueve 3 casillas de golpe.
    girarDerecha()Gira a la derecha sin moverse de casilla.
    girarIzquierda()Gira a la izquierda sin moverse de casilla.
    plantar()Planta una flor en la casilla donde está Robi.
    faltaFlor()Pregunta: ¿esta casilla necesita una flor? (sí / no)
    hayRoca()Pregunta: ¿hay una roca justo delante?
    decir("hola")Escribe un mensaje en la consola.

    Lo que aprenderás

    • Orden: el código se lee de arriba a abajo.
    • Funciones: órdenes con paréntesis, como avanzar().
    • Bucles: for (let i = 0; i < 3; i++) { … } repite sin copiar.
    • Variables: let n = 5; guarda un valor con nombre.
    • Condicionales: if (faltaFlor()) { … } decide.
    • Listas: [1, 3, 3] varios valores juntos.

    🔒 El bucle while está desactivado: si no termina nunca, la página se quedaría congelada. Usa for, que siempre lleva un final.
